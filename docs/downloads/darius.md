# Darius DAST Downloads

Download the latest Darius DAST scanner for your platform. Darius is a single statically compiled binary with no external dependencies.

## Latest Release

| Platform | Architecture | Binary | Download |
|---|---|---|---|
| macOS | Apple Silicon (M1/M2/M3/M4) | `darius-darwin-arm64` | [Download](https://thinkengine.io/dast/settings) |
| macOS | Intel | `darius-darwin-amd64` | [Download](https://thinkengine.io/dast/settings) |
| Linux | x86_64 | `darius-linux-amd64` | [Download](https://thinkengine.io/dast/settings) |
| Linux | ARM64 | `darius-linux-arm64` | [Download](https://thinkengine.io/dast/settings) |
| Windows | x86_64 | `darius-windows-amd64.exe` | [Download](https://thinkengine.io/dast/settings) |

Downloads are available from the ThinkEngine dashboard under **DAST > Settings**.

## Verify Installation

```bash
darius version
```
